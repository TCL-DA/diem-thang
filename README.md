# Điểm tháng

Trang theo dõi điểm thẻ việc hằng tháng. Số liệu nằm trong `du-lieu.enc.json`, mã hoá trong trình duyệt
(khoá dẫn bằng Argon2id 64 MB × 4 vòng, dữ liệu AES-GCM 256). Repo chỉ chứa giao diện — không có số liệu rõ.

Số liệu được kéo và đóng gói ở máy riêng rồi đẩy lên; trang chỉ giải mã khi nhập đúng mật khẩu.
